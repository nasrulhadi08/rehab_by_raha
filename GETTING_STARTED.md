## 🆘 If Something Doesn't Work

### Common Issues & Solutions:

**White blank page?**
- Check: `http://localhost/phpmyadmin`
- Ensure database exists
- Check PHP error logs

**Images not showing?**
- Verify images in: `assets/images/`
- Check exact filenames match
- Use correct extensions

**Forms not submitting?**
- Open browser DevTools (F12)
- Check Console tab for errors
- Verify `php/` folder files exist

**Database error?**
- Ensure MySQL is running
- Check credentials in `db_config.php`
- Default: username `root`, password empty

**See DATABASE_MANAGEMENT.md for more solutions**
